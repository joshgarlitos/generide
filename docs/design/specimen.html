generide window kit

This page shows every component in rct2/webui_static/tokens.css, the stylesheet the web UI uses, dressed as generide's own screens. The look follows RollerCoaster Tycoon 2: bevelled windows on a park backdrop, one colour per kind of window, and square corners throughout.

All ride numbers on this page are example data. The window colours come from the game's 256-colour palette as published in OpenRCT2's source.
